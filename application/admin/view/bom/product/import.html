导入模板格式说明

字段名 必填 数据类型 说明
产品名称 是 文本 产品的唯一名称，不能重复
产品描述 否 文本 产品的详细描述信息
长度公式 否 文本 如：297 或 =L*0.8（支持公式）
宽度公式 否 文本 如：210 或 =W*0.6（支持公式）
高度公式 否 文本 如：30 或 =H+10（支持公式）
状态 否 文本 active（启用）或 inactive（禁用），默认为 active
注意事项：
  • Excel文件第一行必须是字段标题
  • 产品名称不能为空且不能重复
  • 公式支持基本数学运算和L、W、H变量
  • 建议一次导入不超过1000条记录
